# Portfolio Website

## Overview
This is a modern, responsive portfolio website generated from your PDF profile. It is built with Vanilla HTML, CSS, and JS.

## How to Configure
1. Open `script.js`.
2. Find the line: `const GOOGLE_FORM_URL = "PASTE_GOOGLE_FORM_LINK_HERE";`
3. Replace the placeholder with your actual Google Form URL.

## How to Run Locally

### Option 1: Python (Recommended)
If you have Python installed:
1. Open a terminal in this directory.
2. Run: `python -m http.server 8000`
3. Open `http://localhost:8000` in your browser.

### Option 2: Live Server (VS Code)
1. Right-click `index.html`.
2. Select "Open with Live Server".

## Features
- **Profile Data**: Automatically loaded from `profile.json`.
- **Dark/Light Mode**: Persists across refreshes.
- **Responsive**: Works on mobile and desktop.
- **Interactive**: Scroll animations and hover effects.
